# Руководство по интеграции системного справочника в промпты

## Обзор

Системный справочник помогает LLM-модели более точно категоризировать задачи по источникам и системам взаимодействия для проекта "МП Спортмастер".

## Созданные файлы

1. **`systems_reference.txt`** - Полный справочник с описаниями систем
2. **`systems_reference_compact.txt`** - Компактная версия для интеграции в промпты
3. **`detailed_v3_with_systems.txt`** - Обновленный промпт генерации категорий
4. **`detailed_v2_with_systems.txt`** - Обновленный промпт консолидации категорий

## Использование

### Для генерации категорий
Установите в конфигурации:
```python
CATEGORY_GENERATION_PROMPT = "detailed_v3_with_systems"
```

### Для консолидации категорий  
Установите в конфигурации:
```python
CATEGORY_CONSOLIDATION_PROMPT = "detailed_v2_with_systems"
```

## Интеграция в существующие промпты

Добавьте в начало любого промпта компактную версию справочника:

```
СПРАВОЧНИК СИСТЕМ "МП Спортмастер":
ВНУТРЕННИЕ: CmsGate, ContentGate, GeoGate, OrderGate, PersGate, PGate, ProductGate, UserGate, Оркестратор диалогов
ВНЕШНИЕ ПЛАТЕЖНЫЕ [Ext]: SberPay, Yandex Pay, Сбербанк интернет-эквайринг, СБП, Тинькофф
ВНЕШНИЕ АНАЛИТИЧЕСКИЕ [Ext]: AppMetrica, AppsFlyer, Insider, InAppStory, UX Feedback
ВНЕШНИЕ УВЕДОМЛЕНИЯ [Ext]: APNS, Firebase Cloud Messaging
ВНЕШНИЕ СОЦИАЛЬНЫЕ [Ext]: VK ID, Одноклассники, Firebase
ВНЕШНИЕ ИНФРАСТРУКТУРНЫЕ [Ext]: FortiGate, Qrator, Sentry, Яндекс Геокодер
ВНЕШНИЕ БИЗНЕС [Ext]: Aplaut, Streamerce, ПЛАЙТ

ИСПОЛЬЗОВАНИЕ: При анализе задач ищи упоминания этих систем для точной категоризации источников проблем.
```

## Примеры категоризации

- **Платежные проблемы**: "SberPay - Платежные операции"
- **Уведомления**: "Firebase Cloud Messaging - Push-уведомления"
- **Каталог**: "ProductGate - Управление товарами"
- **Авторизация**: "VK ID - Социальная авторизация"

## Обновление справочника

При изменении списка систем обновите:
1. `systems_reference.txt` - полную версию
2. `systems_reference_compact.txt` - компактную версию  
3. Промпты, использующие справочник
