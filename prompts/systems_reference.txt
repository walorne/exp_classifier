СПРАВОЧНИК ВЗАИМОДЕЙСТВУЮЩИХ СИСТЕМ ДЛЯ "МП Спортмастер"

При анализе задач используй этот справочник для точной идентификации источников проблем и инициаторов обращений.

ВНУТРЕННИЕ СИСТЕМЫ СПОРТМАСТЕР:
- CmsGate - система управления контентом
- ContentGate - шлюз контента
- GeoGate - геолокационные сервисы  
- OrderGate - система управления заказами
- PersGate - персонализация пользователей
- PGate - платежный шлюз
- ProductGate - система управления товарами
- UserGate - система управления пользователями
- Оркестратор диалогов - координация диалоговых процессов

ВНЕШНИЕ ПЛАТЕЖНЫЕ СИСТЕМЫ [Ext]:
- SberPay - платежная система Сбербанка
- Yandex Pay - платежная система Яндекса
- Сбербанк интернет-эквайринг - эквайринговые услуги Сбербанка
- СБП - Система быстрых платежей
- Тинькофф - платежная система Тинькофф Банка

ВНЕШНИЕ АНАЛИТИЧЕСКИЕ И МАРКЕТИНГОВЫЕ СИСТЕМЫ [Ext]:
- AppMetrica - аналитика мобильных приложений
- AppsFlyer - атрибуция мобильного маркетинга
- Insider - платформа персонализации
- InAppStory - интерактивные истории в приложениях
- UX Feedback - система сбора обратной связи пользователей

ВНЕШНИЕ СИСТЕМЫ УВЕДОМЛЕНИЙ [Ext]:
- APNS - Apple Push Notification Service
- Firebase Cloud Messaging - система push-уведомлений Google

ВНЕШНИЕ СОЦИАЛЬНЫЕ И АВТОРИЗАЦИОННЫЕ СИСТЕМЫ [Ext]:
- VK ID - авторизация через ВКонтакте
- Одноклассники - социальная сеть
- Firebase - платформа разработки Google

ВНЕШНИЕ ИНФРАСТРУКТУРНЫЕ СИСТЕМЫ [Ext]:
- FortiGate - сетевая безопасность
- Qrator - защита от DDoS атак
- Sentry - мониторинг ошибок
- Яндекс Геокодер - геокодирование адресов

ВНЕШНИЕ БИЗНЕС-СИСТЕМЫ [Ext]:
- Aplaut - внешняя бизнес-система
- Streamerce - e-commerce платформа
- ПЛАЙТ - внешняя система

ПРАВИЛА ИСПОЛЬЗОВАНИЯ СПРАВОЧНИКА:

1. ТОЧНАЯ ИДЕНТИФИКАЦИЯ:
   При обнаружении в тексте задач названий из справочника, используй их ТОЧНО как указано
   
2. КАТЕГОРИЗАЦИЯ ПО ТИПАМ:
   - Внутренние системы (*Gate, Оркестратор) - проблемы инфраструктуры Спортмастера
   - Платежные системы [Ext] - проблемы с оплатой и финансовыми операциями  
   - Аналитические системы [Ext] - проблемы с отслеживанием и аналитикой
   - Социальные системы [Ext] - проблемы авторизации и социальных функций
   - Инфраструктурные [Ext] - проблемы безопасности и мониторинга

3. ФОРМИРОВАНИЕ КАТЕГОРИЙ:
   Используй названия систем для создания точных категорий вида:
   - "[Система] - [Тип проблемы]" 
   - "[Инициатор] - [Система] - [Компонент]"
   
   Примеры:
   - "SberPay - Платежные операции"
   - "Firebase - Push-уведомления"  
   - "ProductGate - Каталог товаров"

4. ОБРАБОТКА СОКРАЩЕНИЙ:
   Если в задачах встречаются сокращения (СБП, ПЛАЙТ), сопоставляй их с полными названиями из справочника

ВНИМАНИЕ: 
- Не все проблемы связаны с внешними системами - многие могут касаться внутренней разработки
- Используй справочник как дополнение к анализу, а не как ограничение
- Если система не указана в справочнике, но четко упоминается в задаче - включай её в анализ
